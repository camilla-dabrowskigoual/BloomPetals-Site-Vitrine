
# 🌸 BloomPetals – Site vitrine

## 📖 Présentation du projet

BloomPetals est un site vitrine dédié à une entreprise de fleuristerie, réalisé dans le cadre de ma formation à La Plateforme à Cannes.

L'objectif de ce projet est de concevoir un site web moderne, élégant et responsive, mettant en valeur les services, les créations florales, l'équipe et les valeurs de l'entreprise.

## 🌷 Les pages du site

- **Accueil** : présentation de BloomPetals et de ses services.
- **Entreprise** : présentation de l'équipe et des valeurs de l'entreprise.
- **Réalisations** : galerie de créations et de compositions florales.
- **Contact** : formulaire de contact et coordonnées de l'entreprise.

## 💻 Technologies utilisées

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git et GitHub
- Visual Studio Code

## ✨ Fonctionnalités

- Navigation entre les différentes pages.
- Galerie de créations florales.
- Interface de formulaire de contact.
- Effets visuels et personnalisation graphique.
- Design responsive adapté aux ordinateurs, tablettes et smartphones.

## 🚀 Lancer le projet

1. Cloner le dépôt GitHub.
2. Ouvrir le dossier BloomPetals dans Visual Studio Code.
3. Ouvrir le fichier `accueil/index.html` avec Live Server.
